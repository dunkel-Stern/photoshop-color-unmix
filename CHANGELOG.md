# Changelog

## 2.0.0

UI and packaging refresh while keeping the same unmix math.

- Flattened the panel: no accordion sections for a simple three-step flow
- Spectrum UXP controls for buttons, text fields, and the tolerance slider
- Clear ready / blocked document state with auto-refresh on common Photoshop events
- Quick color presets (White, Soft white, Warm paper, Black) plus From FG
- Friendlier status copy and primary action labeled **Remove color**
- Raised `minVersion` to **24.4.0** (Imaging API requirement)
- Preferred panel size tuned for the new layout
- Version bump to 2.0.0
